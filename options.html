Gemini GitHub Bridge

חיבור Gemini ל-GitHub עם אישור לפני כל כתיבה, תצוגת Diff, ו-Branch + PR כברירת מחדל.

חיבור ל-GitHub

הטוקן נשמר מקומית בדפדפן ונשלח רק ל-GitHub API. הוא אינו מצורף לפרומפטים של Gemini.

מאגר וענף

במצב Branch + PR כל קבוצת השינויים נוצרת ב-commit יחיד על ענף חדש, ורק לאחר מכן נפתח Pull Request.
